# @cmdless/ui-sdk

Shared types and helpers for building on cmdless UI, split by where they run.

## Exports

- **`@cmdless/ui-sdk`** — platform-agnostic.
  - `types` — `ShowTypes`, `MessageBoxTypes`, and the card and form shapes (`AdaptiveCard`, `CardEvent`, `CardView`, `FormView`).
  - The agent prompts as cards: `elicitationCard`/`elicitationResult` (MCP's and ACP's elicitation, form mode) and `permissionCard`/`permissionResult` (ACP's permission request) — a request in, a card to show; what the card ended with in, the protocol's answer out. Closing the card is cancelling.
  - `Cmdless`, what a window's page gets as `window.cmdless`: `resolve(value)` ends the window, and `backend` is the connection to its backend, started as the page loads — or nothing, if it has none — and `connect()` opens another (use `connect` from `/browser`).
  - The host's own channels to a window's preload (`cmdlessIPC`, `cmdlessViewIPC`, `createElectronIPC`, `createElectronViewIPC`) — main ↔ preload only.

- **`@cmdless/ui-sdk/node`** — Node only.
  - `UIHost` — a connection to a host (one Electron process per app name, run by [`@cmdless/ui-runtime`](../../apps/ui-runtime)).
    - `UIHost.create({ app?, cmdlessRoot?, timeoutMs?, initialize? })` starts the host for `app`, or joins it if it's already running. Without `app`, the host is a throwaway one of this caller's own. `initialize(host)` sets the UIHost up before `create` hands it back — and, for the owner, before anything else can join: a second run of the app waits until it has settled, so whatever it sets up (`onMessage`, a tray) is there before another UIHost can reach it. If it throws, `create` does, and leaves the host.
    - `openWindow(params)`, `openDialog(params)`, `openCard(params)` and `openForm(params)` open a window, a message box, an [Adaptive Card](https://adaptivecards.io) or a JSON Schema form; `createTray(params)` creates a tray icon (an empty `icon` uses the runtime's own) and `showNotification(params)` an OS notification. Each resolves to a remote handle once the host has. A handle's `closed` settles with the value it ends with — a window's resolve or the redirect it caught, the dialog's chosen button (and its checkbox, if it has one), a card's `Action.Submit` (`{ action, inputs }`), a form's data — or nothing if it was closed by hand; `close(value?)` ends it, and `focus()` brings its window to the front (restoring it if it's minimized). Anything can be opened from another handle (`handle.openWindow(...)`, ...) to open in front of it. A tray reports clicks, and a card each `Action.Execute`, through `onEvent`; `update(...)` changes either.
    - How a window, card or form looks goes in `window: { width?, height?, title? }`. Cards and forms fit their window's height to what they show unless a height is given.
    - A window's **backend** (`params.backend`) is an accept function — `protocol.accept(configure)` from [`@cmdless/rpc-sdk`](../rpc-sdk), or a host's own `accept` to share one (and its store) across windows. Its page calls `connect(protocol, configure?)` from `/browser`, and talks to this process directly: the host only introduces them, with a token for one connection that stays in the window's preload. The UIHost keeps it under a key of its own, made before the window opens, and drops it when the window ends. A page's first `connect` takes the connection started as it loaded, and any after it (a component mounted again, say) get their own; a page whose window has no backend sees `window.cmdless.backend` unset, and `connect` fails at once rather than waiting.
    - **Factories** package something to open with its own typed params — a window and the backend serving it, say: `const logViewer = UIHost.factory(async (opener, params: { file: string }) => opener.openWindow({ ... }))`. `host.open(logViewer, params)` opens it on its own, `handle.open(logViewer, params)` in front of that handle, and `UIHost.show(logViewer, params, options?)` as a one-shot. The opener (`UIOpener`) is a host or a handle: either opens windows, dialogs, cards and forms, and `.host` reaches the host itself.
    - `UIHost.showWindow`, `showDialog`, `showCard`, `showForm`, `showElicitation` and `showPermission` are the one-shot forms: start or join a host, show one thing, and hand back what it ended with. Each takes the params first and the host options (`{ app, cmdlessRoot, timeoutMs }`) last, optionally.
    - **Between UIHosts of one app:** each connection has an id (`connectionId`), and `params.hasSingleInstanceLock` says whether it's the owner. `connections()` lists every UIHost connected to the host, with which one is the owner. `send(message, to?)` hands a message (anything JSON carries) to another of them through the host: to the owner unless `to` names a connection. It settles once the host has passed it on, and fails for a connection that isn't there. `onMessage(({ from, message }) => ...)` hears them. So a second run of an app can pass what it was asked to the one that's running, `send({ ... })`, then leave.
    - `dispose()` leaves the host; for its owner (the one whose creator started it), that ends it.
  - `getCmdlessApp`/`setCmdlessApp`, `setCmdlessUrl`/`acquireCmdlessUrl` — accessors for cmdless's environment, so callers never read `process.env` themselves. Each setter writes to this process's env, or to an env object passed in for a child about to be spawned. A dev-mode Vite plugin (see `apps/hangar-ui`'s `vite.config.ts`) can publish its dev server's URL with `setCmdlessUrl(url, env)` before spawning a consumer's bin, for the bin to show instead of its built renderer.
  - An app name is a package name's shape (`@scope/name`, in lowercase letters, digits and `. _ ~ -`): `getCmdlessApp` and `setCmdlessApp` refuse anything else, since it names `userData`, the app's bundles and its lock. A throwaway app's name is the prefix and a UUID, exactly.
  - `resolveRuntimeBin(cmdlessRoot?)` — ui-runtime's bin at the version this package speaks: the local install when it's that version, or else that version from the cmdless root's cache.
  - The ephemeral-app helpers (`getEphemeralPrefix`, `isEphemeralCmdlessApp`, `isEphemeralUserData`), and the few [`@cmdless/core`](../core) helpers the host and `@cmdless/ui` use.

- **`@cmdless/ui-sdk/browser`** — renderer only: the `window.cmdless` type, and `connect(protocol, configure?)`, which connects a window's page to the backend it was opened with. `configure` sets handlers up before it listens, so nothing the backend sends at once is missed.
